# HealthSetu AI - Smart Health Centre & Supply Chain Management

HealthSetu AI is an AI-driven, offline-first health centre management system designed for Primary Health Centres (PHCs) and Community Health Centres (CHCs).

## 🚀 Key Features
- 🌐 Multilingual Vernacular Interface (Hindi / English)
- 🎙️ Web Speech API Interactive Voice Assistant
- 📶 Offline-First Sync & Queue Simulation
- 📊 Neural AI Medicine Stock & Demand Forecasting
- 🚨 Automated Emergency Supply Auto-Routing

## 🛠️ Architecture & Tech Stack
- Frontend: HTML5, CSS3 (Custom Responsive System), JavaScript (ES6+)
- Testing: Automated Jest Suite (`test.js`) & Native Runtime Verification
- Security: DOM Input Sanitization & Content Security Policies
